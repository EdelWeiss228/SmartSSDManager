# macOS Disk Mounter (SmartSSDManager)

Фоновый демон и веб-панель настроек для macOS, которые аккуратно управляют внешними SSD и их разделами. Утилита отмонтирует настроенные тома при простое или перед уходом Mac в сон, чтобы не появлялась ошибка «Диск не был извлечён должным образом» (Disk Not Ejected Properly).

## Возможности

- **Автоотмонтирование при сне:** извлекает настроенные внешние диски перед сном (по умолчанию — без `force`).
- **Таймер бездействия:** отмонтирует диск, если к нему не обращались заданное время.
- **Точное определение диска:** используется `diskutil ... -plist`, а не парсинг текста. Том поднимается до настоящего физического диска (например, `disk4`), минуя синтезированные APFS-контейнеры.
- **Защита от внутренних и загрузочных дисков:** демон откажется размонтировать внутренний диск или диск, с которого загружена macOS, даже если его имя случайно попало в конфиг.
- **Защита от циклов:** после авто-извлечения диск не трогается повторно, пока на нём не появится активность или пока он не будет смонтирован пользователем позже. Это исправляет прежнее поведение, когда диск монтировался обратно и демон снова его извлекал каждые пару минут.
- **Безопасный режим по умолчанию:** `force` выключен. Если диск занят, `diskutil` вернёт ошибку, демон подождёт и повторит позже, вместо того чтобы рвать открытые файлы.
- **Веб-панель:** локальный Python-сервер с тёмным интерфейсом.
- **Ярлыки:** `.app` на Рабочем столе, которые монтируют диск и открывают его в Finder.

## Компоненты

- `src/SmartSSDManager.swift` — фоновый демон.
- `src/smartssd_settings.py` — локальная веб-панель настроек.
- `install.sh` — сборка и установка.

## Установка

```bash
git clone https://github.com/EdelWeiss228/SmartSSDManager.git
cd SmartSSDManager
chmod +x install.sh
./install.sh
```

Скрипт:

1. Компилирует демон (`swiftc -O`).
2. Копирует бинарник и панель в `~/.local/bin`.
3. Регистрирует LaunchAgent `com.user.smartssd` через современный `launchctl bootstrap`.
4. Запускает демон и проверяет, что он жив.

Лог: `~/Library/Logs/SmartSSDManager.log`
Конфиг: `~/.local/bin/smartssd_config.json`

## Настройка

```bash
python3 ~/.local/bin/smartssd_settings.py
```

В панели можно:

- выбрать подключённые внешние тома из списка (внутренние диски и загрузочный том исключены);
- видеть, смонтирован том или нет, и удалять тома из отслеживания;
- задать таймер простоя;
- включить/выключить извлечение перед сном;
- включить принудительное извлечение (не рекомендуется);
- сохранить настройки и перезапустить демон.

### Конфиг

```json
{
  "volumes": ["My SSD"],
  "timeoutMinutes": 10,
  "cooldownMinutes": 10,
  "forceUnmount": false,
  "unmountOnSleep": true
}
```

- `timeoutMinutes` — сколько минут без открытых файлов ждать перед извлечением.
- `cooldownMinutes` — пауза после неудачной попытки (занятый диск), чтобы не долбить его каждую минуту.
- `forceUnmount` — `diskutil unmountDisk force`. Может прервать запись; по умолчанию `false`.
- `unmountOnSleep` — извлекать перед сном.

## Диагностика

```bash
~/.local/bin/SmartSSDManager --check
```

Показывает, найден ли том, к какому физическому диску он относится, является ли диск внешним и есть ли на нём открытые файлы. Ничего не размонтирует.

Разовое извлечение:

```bash
~/.local/bin/SmartSSDManager --unmount-now
# при необходимости (опасно):
~/.local/bin/SmartSSDManager --unmount-now --force
```

Пробный запуск без реальных действий:

```bash
~/.local/bin/SmartSSDManager --dry-run
```

## Как это работает

1. Каждые 60 секунд демон читает конфиг и ищет настроенные тома через `diskutil list -plist`.
2. Для каждого смонтированного тома определяется физический диск и проверяется, что он не внутренний и не загрузочный. Внутренние и системные диски игнорируются.
3. Занятость проверяется через `lsof -F pcn` (без рекурсивного обхода всего диска, как было раньше с `lsof +D`).
4. Если открытых файлов нет дольше `timeoutMinutes`, выполняется `diskutil unmountDisk` **без** `force`.
5. После успешного извлечения диск помечается как «остывающий»: если система или пользователь смонтирует его обратно в течение 2 минут, демон не будет снова его извлекать. Если позже появится активность или пользователь смонтирует диск заново, таймер снова взводится.
6. При неудаче (диск занят) следующая попытка будет не раньше чем через `cooldownMinutes`.

## Исправления по сравнению с первой версией

- `diskutil`-статусы больше не игнорируются: успех/ошибка пишутся в лог.
- Определение физического диска через plist вместо хрупкого парсинга строк.
- Жёсткая защита от размонтирования внутреннего диска.
- `force` отключён по умолчанию.
- Убрана рекурсивная `lsof +D`, которая грузила диск и сама мешала ему «простаивать».
- Добавлена защита от повторного извлечения после автоматического монтирования.
- `restart_daemon` использует `launchctl kickstart`, проверяет, что сервис остался загруженным, и умеет возвращать plist из состояния `.disabled`.
- Панель настроек корректно URL-кодирует имена томов и экранирует HTML.
- Веб-панель показывает только внешние физические тома и умеет выбирать их из списка.
- Установщик пишет лог в `~/Library/Logs`, а не в `/tmp`.
